Automação de pipeline CI/CD com GitHub Actions

Projeto desenvolvido para demonstrar a integração e a entrega contínuas de uma aplicação web, desde o envio do código até a publicação automática no GitHub Pages.

#pipeline Conhecer a pipeline

Objetivo do projeto

Automatizar o processo de validação e publicação da aplicação.

A pipeline foi criada para identificar alterações enviadas à branch principal do repositório e executar automaticamente as etapas necessárias para publicar a página no GitHub Pages. A automação reduz intervenções manuais, padroniza o processo de deploy e permite acompanhar o resultado de cada execução.

Etapas da pipeline

Fluxo executado automaticamente após um push na branch main.

1

Push

Uma alteração é enviada para a branch main do repositório.

2

Checkout

O GitHub Actions obtém os arquivos mais recentes do projeto.

3

Validação

A pipeline verifica se o arquivo index.html está presente.

4

Deploy

Os arquivos são publicados automaticamente no GitHub Pages.

Status do deploy

Resultado esperado após a execução completa do workflow.
